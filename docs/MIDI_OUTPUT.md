# MIDI Output & DAW Integration Guide

> **Melody Mate v2 (DAW Edition)**  
> **Status:** Production Reference  
> **Applicable Components:** Sound & Mix Dock (`S`), MIDI Output Workstation, Transport Output Router

---

## 1. Overview & Architecture

Melody Mate provides direct, low-latency Web MIDI streaming from its generative engine directly to external hardware synthesizers, audio interfaces, and digital audio workstations (DAWs) running on the same computer.

```text
┌────────────────────────────────────────────────────────────────────────┐
│                              Melody Mate                               │
│                                                                        │
│  [Melody Track] ──┐                                                    │
│                   ├──► [Transport Output Router]                       │
│  [Chords Track] ──┘         │                     │                    │
│                             ▼                     ▼                    │
│                     [Internal Synth]      [Web MIDI Output]            │
│                     [Effects & Faders]            │                    │
│                             │                     │ (Note / Velocity)  │
│                             ▼                     ▼                    │
│                     [Web Audio Out]        [OS / CoreMIDI]             │
└────────────────────────────┬──────────────────────┬────────────────────┘
                             │                      │
                             │                      ▼
                             │             ┌──────────────────┐
                             │             │ Virtual MIDI Bus │ (IAC / loopMIDI)
                             │             └────────┬─────────┘
                             │                      │
                             ▼                      ▼
                     [Studio Monitors] ◄─── [DAW / Hardware]
                        (Internal)              (External Synth)
```

### Core Operating Principles

1. **Host-Provided Ports Only:**  
   Melody Mate does not create virtual operating system drivers. Web MIDI is a client API that enumerates ports already exposed by the operating system, hardware interfaces, or virtual drivers.
2. **Pure Note Streaming (No MIDI Clock in MVP):**  
   Melody Mate streams musical note events (**Note-On**, **Note-Off**, and **Velocity**) on user-assigned MIDI channels according to its internal transport timeline. In the initial release, it does not send MIDI Clock (`0xF8`), MIDI Start/Stop (`0xFA`/`0xFC`), or Song Position Pointer (`0xF2`).
3. **No Audio Return Over MIDI:**  
   MIDI cables and virtual buses carry musical control data, not audio signals. Sound is generated by your external synthesizer or DAW instrument. The audio output must be monitored directly through your DAW or audio interface.
4. **Mixer Isolation:**  
   Melody Mate's track volume faders, pan controls, ADSR envelopes, filter cutoffs, and master volume affect internal Web Audio synthesis only. They do **not** transmit MIDI Volume (`CC #7`), Pan (`CC #10`), or Expression (`CC #11`). Note dynamics are controlled exclusively via note velocities in the piano roll and velocity lane.
5. **Secure Context & Explicit Opt-In:**  
   Browsers require a Secure Context (`https://` or `http://localhost`) to access Web MIDI. Melody Mate never prompts for MIDI permissions on app launch; access is requested only when you click **Enable MIDI** in the Sound & Mix dock.

## 2. macOS Setup (IAC Driver & Logic Pro)

macOS provides a built-in virtual MIDI bus called the **IAC Driver (Inter-Application Communication)**. It allows Melody Mate running in Google Chrome to stream MIDI directly into Ableton Live, Logic Pro, REAPER, Studio One, or Bitwig on the same machine.

### Enabling the macOS IAC Driver

1. Open **Audio MIDI Setup** (located in `/Applications/Utilities/` or via Spotlight `Cmd + Space`).
2. Open the MIDI Studio window:
   - In the menu bar, select **Window** → **Show MIDI Studio** (or press `Cmd + 2`).
3. In the MIDI Studio window, locate and double-click the **IAC Driver** icon.
4. In the IAC Driver Properties dialog:
   - Check the box labeled **Device is online**.
   - Under **Ports**, ensure at least one bus exists (default: `Bus 1`). You can add additional buses with the `+` button if desired.
   - Click **Apply**.
5. The IAC bus is now active system-wide as `IAC Driver Bus 1`.

```text
┌──────────────────────────────────────────────┐
│             IAC Driver Properties            │
├──────────────────────────────────────────────┤
│  [x] Device is online                        │
│                                              │
│  Ports:                                      │
│  ┌────────────────────────────────────────┐  │
│  │ Bus 1                                  │  │
│  └────────────────────────────────────────┘  │
│  [+] [-]                                     │
│                                  [ Apply ]   │
└──────────────────────────────────────────────┘
```

### Apple Logic Pro Setup

Logic Pro automatically listens to virtual MIDI ports and also offers its own internal virtual input.

#### Method A: Using IAC Driver

1. In Melody Mate, set the track MIDI port to `IAC Driver Bus 1`.
2. Open **Logic Pro**.
3. Create a **Software Instrument** track (e.g., Alchemy, Retro Synth, or Sampler).
4. In the track inspector, set **MIDI In** to `IAC Driver Bus 1` and specify the MIDI Channel (`1` for Melody, `2` for Chords).
5. Click the **Input Monitoring** (`I`) button or **Record Enable** (`R`) button on the track to hear incoming notes.

#### Method B: Logic Pro Virtual In

1. In Logic Pro, open **Settings** (or **Preferences**) → **MIDI** → **Inputs**.
2. Ensure **Logic Pro Virtual In** is enabled.
3. In Melody Mate, click **Refresh ports**. Select `Logic Pro Virtual In` as your output port.

## 3. Ableton Live Setup

Ableton Live requires explicit configuration in its MIDI Preferences before an incoming virtual port will pass note data to tracks.

### Step 1: Configure MIDI Preferences

1. Open Ableton Live.
2. Open **Settings** (macOS: `Cmd + ,` | Windows: `Ctrl + ,`).
3. Navigate to the **Link, Tempo & MIDI** tab.
4. In the **MIDI Ports** table at the bottom, find the input entry corresponding to your port:
   - macOS: `Input: IAC Driver (Bus 1)`
   - Windows: `Input: loopMIDI Port`
   - Hardware: `Input: <Your USB MIDI Interface>`
5. Turn **ON** the **Track** button for this input.
   - **Track = ON**: Allows Live to receive incoming Note and Velocity data on MIDI tracks.
   - **Sync = OFF**: Melody Mate does not transmit MIDI clock; leave Sync off.
   - **Remote = OFF**: Prevents notes from inadvertently triggering mapped DAW buttons or macros.

```text
┌─────────────────────────────────────────────────────────────┐
│  Live Preferences: Link, Tempo & MIDI                       │
├─────────────────────────────────────────────────────────────┤
│  MIDI Ports:                                                │
│  Input: IAC Driver (Bus 1)       [Track: ON] [Sync: OFF] [Remote: OFF] │
└─────────────────────────────────────────────────────────────┘
```

### Step 2: Route to Live Tracks

1. In Live's Session or Arrangement View, create a **MIDI Track** (`Cmd + Shift + T`).
2. Show the **In/Out** section (`Cmd + Option + I`).
3. Configure the track routing:
   - **MIDI From**: Select `IAC Driver (Bus 1)`.
   - **Channel**: Select channel `1` (for Melody) or channel `2` (for Chords), matching the channel assigned in Melody Mate.
   - **Monitor**: Set to **In** for live listening, or set to **Auto** and engage **Record Arm**.
4. Drop an instrument device (e.g. Drift, Wavetable, Simpler) onto the track.
5. In Melody Mate, press **Play** or click **Test note**. The track in Live will register incoming MIDI and sound the instrument.

## 4. Cockos REAPER Setup

1. Open REAPER.
2. Open **Preferences** (`Cmd + ,` on macOS / `Ctrl + P` on Windows).
3. Under **Audio**, select **MIDI Devices**.
4. Under **MIDI inputs to listen to:**, find `IAC Driver Bus 1` (or `loopMIDI`).
5. Right-click the port and select **Enable input**.
6. Click **Apply** and **OK**.
7. Create a new track (`Cmd + T` / `Ctrl + T`).
8. On the track header:
   - Click the **Record Arm** button.
   - Click the Input selector → select **Input: MIDI** → `IAC Driver Bus 1` → **Channel 1** (or Channel 2).
   - Click the **Record Monitoring** speaker icon so it is set to **ON** (green).
9. Add your preferred virtual instrument to the track FX chain.

## 5. Hardware Synthesizer & USB-MIDI Setup

Melody Mate can trigger physical desktop synths, Eurorack MIDI modules, and vintage hardware via USB or dedicated MIDI interfaces.

### Connection Workflow

1. Connect your synthesizer or 5-pin DIN interface to your computer via USB.
2. Ensure your hardware is powered on and any manufacturer drivers are installed.
3. In Melody Mate, open the **Sound & Mix** dock (`S`) and switch to the **MIDI Output** view.
4. Click **Enable MIDI** (or **Refresh ports** if already enabled).
5. In the **Port** dropdown for Melody or Chords, select your hardware device (e.g. `Moog Sub 25`, `Elektron Digitakt`, or `MOTU MIDI Express`).
6. Set the **Channel** to match your synthesizer's receiving channel (default: Ch 1 for Melody, Ch 2 for Chords).
7. Switch the track mode to **MIDI** (to mute internal synthesis) or **Both** (to layer internal and hardware sounds).
8. Click **Test note** to verify external triggering.

### Hardware Considerations & Serial Latency

- **USB-MIDI Class Compliant:** Modern USB synthesizers communicate directly without driver installation.
- **5-Pin DIN-5 Cabling:** Traditional MIDI cables operate at 31,250 baud. When streaming dense chord voicings alongside fast arpeggios, MIDI messages serialize at approximately 1 ms per 3-byte message. Melody Mate's timing scheduler buffers note releases to prevent byte starvation or voice truncation.
- **Audio Monitoring:** Hardware audio must be cabled back into your audio interface and monitored through your studio speakers or DAW.

## 6. Windows Setup & Loopback Routing

### Windows MIDI Services & Windows 11

Microsoft is actively developing **Windows MIDI Services** (an open-source modernized MIDI subsystem). While Windows MIDI Services supports native loopback endpoints, browser Web MIDI integration (via Chromium's Windows MIDI backend) varies across Windows builds and Chromium release channels.

Melody Mate makes **no generic out-of-the-box browser virtual port promise** on Windows without an established loopback driver.

### Verified Solution: Tobias Erichsen loopMIDI

The proven, industry-standard solution for Windows DAW loopback routing is **loopMIDI** by Tobias Erichsen:

1. Download and install loopMIDI from [tobias-erichsen.de/software/loopmidi.html](https://www.tobias-erichsen.de/software/loopmidi.html).
2. Launch loopMIDI.
3. In the **New port-name** field, enter a name (e.g. `MelodyMate Loop`) and click the `+` button.
4. The virtual port is now active in Windows.
5. In Google Chrome or Microsoft Edge, open Melody Mate, click **Enable MIDI**, and select `MelodyMate Loop`.
6. In your Windows DAW (Ableton, FL Studio, Cubase, Studio One, REAPER), enable `MelodyMate Loop` as an active MIDI input.

## 7. Linux Setup (ALSA & PipeWire)

On Linux, Chromium interacts with Web MIDI through the ALSA Sequencer API (`/dev/snd/seq`).

### Virtual Loopback via `snd-virmidi`

To create virtual loopback ports accessible to both the browser and Linux DAWs (Bitwig, Ardour, REAPER for Linux):

1. Load the virtual MIDI kernel module:
   ```bash
   sudo modprobe snd-virmidi midi_devs=1
   ```
2. Virtual ports will appear in ALSA as `VirMIDI 1-0`.
3. In Chromium, open Melody Mate and click **Enable MIDI**. Select `VirMIDI 1-0`.
4. In your DAW or modular patchbay (e.g., **QjackCtl**, **Helvum**, or **Patchance**), route `VirMIDI 1-0` to your synth track.

### Sandbox & Container Considerations

- If running Chrome/Chromium via **Flatpak** or **Snap**, the container sandbox may restrict access to `/dev/snd/seq`. If no ports appear in Melody Mate, use the native system package (e.g., `.deb`, `.rpm`, or Arch package) or grant device access permissions via Flatseal (`--device=all`).

## 8. Browser Compatibility & Troubleshooting

| Browser             | Web MIDI Support          | Requirements & Behavior                                                                                                                                            |
| :------------------ | :------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Google Chrome**   | **Full (Primary)**        | Chromium 124+ displays a site permission prompt. Works on `https://` and `http://localhost`.                                                                       |
| **Microsoft Edge**  | **Full**                  | Identical to Chrome engine. Requires secure context.                                                                                                               |
| **Brave**           | **Supported**             | Chromium-based; requires MIDI permission and a secure context.                                                                                                     |
| **Mozilla Firefox** | **Supported (Secondary)** | Supported from Firefox 108+. May require site permission prompt confirmation or manual add-on validation depending on OS.                                          |
| **Apple Safari**    | **Unsupported**           | WebKit does not implement the Web MIDI API. Melody Mate gracefully displays `MIDI: Unavailable`; internal synthesis and MIDI file export remain fully operational. |

`MIDIOutput.clear()` is not implemented in Chromium-based browsers. Melody Mate supports these ports by keeping future events in its own queue until they are due, then submitting them immediately. Stop, Mute, route changes and Panic still release owned notes without leaving future attacks in an uncancellable driver queue. This mode follows the configured 10 ms pump interval and is more sensitive to browser scheduling delays than timestamped lookahead on ports with `clear()`. See [MDN browser compatibility](https://developer.mozilla.org/en-US/docs/Web/API/MIDIOutput/clear).

### Troubleshooting Checklist

#### 1. "Web MIDI requires HTTPS or localhost" (`insecure-context`)

- **Cause:** Web MIDI is restricted to Secure Contexts. Accessing Melody Mate across a local LAN IP (e.g., `http://192.168.1.50:5173`) disables the API.
- **Fix:** Access Melody Mate via `http://localhost:5173` or deploy behind a valid HTTPS domain.

#### 2. "No MIDI output devices found on this system" (`no-outputs`)

- **Cause:** Web MIDI initialized successfully, but CoreMIDI / ALSA / Windows reports 0 connected outputs.
- **Fix:** Connect a USB MIDI device or turn on the macOS IAC Driver / loopMIDI. Then click **Refresh ports**.

#### 3. "Web MIDI access was denied" (`denied`)

- **Cause:** The browser permission prompt was rejected.
- **Fix:** Click the site settings lock/tune icon in the browser address bar, reset the **MIDI devices** permission to **Allow**, and reload the page.

#### 4. "Port Disconnected" Banner

- **Cause:** A previously selected USB cable was unplugged or an external virtual driver closed.
- **Fix:** Reconnect the hardware and click **Refresh ports**. Melody Mate preserves your desired routing configuration and automatically rebinds when the port identifier reappears.

#### 5. "MIDI output requires clear() for safe cancellation."

- **Cause:** An older Melody Mate build incorrectly required a browser method that Chromium does not implement. This is an application compatibility error, unrelated to IAC installation or Ableton's MIDI port preferences.
- **Fix:** Reload the updated application, enable MIDI and select the output again. For the Ableton listening test, set the instrument track's **Monitor** to **In**, or use **Auto** with **Record Arm** enabled.

## 9. Operational Behaviors & Best Practices

### Mode Comparison: `Internal` vs `MIDI` vs `Both`

- **`Internal`:** Audio is synthesized exclusively by Melody Mate's internal instruments. External MIDI is silent.
- **`MIDI`:** Internal synthesizer voices are muted. Note events are transmitted exclusively to the assigned external MIDI port. Volume faders and FX in Melody Mate do not affect the output.
- **`Both`:** The musical notes trigger internal synthesis **and** stream to the external MIDI port simultaneously.
  > [!WARNING]
  > **Acoustic Flanging / Double-Sounding:** If you monitor internal audio through your speakers and simultaneously monitor the DAW instrument track, slight buffer differences between Web Audio and DAW audio engines will produce audible chorus or flanging. For external recording, set the track mode to **`MIDI`**.

### Transport Safety & Preview Lock

- **Opt-In Previews:** Auditioning piano roll notes, chord voicings, arpeggio candidates, or takes does not send external MIDI by default. Enable **Send previews to MIDI** in the dock if you want auditioning to sound on your external hardware.
- **Transport Lockout:** During active transport playback, preview clicks and test note triggers are intentionally suppressed on external MIDI routes. This guarantees zero voice collisions, double attacks, or premature Note-Off cancellations during song playback.

### Micro-Timing Offset (-50 ms to +50 ms)

Every audio interface, USB bus, and software instrument introduces varying latencies. If external notes sound slightly ahead or behind Melody Mate's internal click:

- Adjust the **Offset** knob on the track route.
- **Negative values (-ms):** Transmits MIDI earlier to compensate for slow external synth attacks or high DAW buffer latencies.
- **Positive values (+ms):** Transmits MIDI later to align with high-latency internal processing chains.

### Panic & Hardware Disconnects

If a physical MIDI cable is pulled or a synth crashes during playback, external hardware voices may hang because Note-Off messages could not reach the device.

- Click the global **Panic** button in the persistent bottom footer (`Esc` or click).
- Melody Mate immediately purges its scheduled queues, sends explicit Note-Off messages for all recorded active notes, and dispatches standard **All Notes Off** (`CC 123`) and **All Sound Off** (`CC 120`) messages on active channels.
- If a hardware synth remains stuck after being disconnected, use the physical hardware Panic button or power-cycle the synthesizer.
